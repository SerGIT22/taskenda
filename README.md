# Taskenda

App Android de tareas, diseñada como hermana visual de Agenda.

## Base
- Kotlin + Jetpack Compose
- Material 3 Expressive
- Room + MVVM
- Tema dinámico claro/oscuro
- Navegación inferior flotante
- FAB independiente
- Checkbox interactivo con feedback háptico
- Crear, editar, eliminar, completar y marcar como importante

## Próximas fases

2. Listas personalizadas.
3. Subtareas interactivas.
4. Repetición.
